# Manifest notes

`tests/manifest.json` was generated by `tests/contract-tools/classify.mjs` (the grep heuristic of 0101 §9) and then corrected
by hand where the heuristic is wrong. Every hand correction is listed here and lives in `tests/manifest-corrections.json`, which
`classify.mjs` applies by suite name, so regenerating the file keeps them.

## The heuristic

- `libs`: `hooks/lib-*.mjs` files named in an `import(...)`, `from "..."` or `require(...)` form, and present in `hooks/`.
- `kind`: spawns a hook or CLI by path (B) -> `contract`; imports libs (A) -> `internal`; both -> `mixed`; neither -> `static`.
  A spawn is `node [flags] <path>/<script>.mjs`, a variable set to such a path, or `bin/ahd` and `bin/ah-hook`; the script must exist
  in `hooks/`.
- `covers`: the `hooks/*.mjs` and `hooks/hooks.json` paths the file names, the scripts it spawns and the libs it imports. A `.sh`
  wrapper is classified on its own text plus the `tests/test-*.mjs` it runs.
- `lane`: `serial` for the names in `run-all.sh`'s `SERIAL_LANE`; `full` for `SLOW_FIRST` and for a suite that took over 60 s in the
  `results.txt` of a full run (`--timings`); otherwise `fast`.
- `reads_source`: a line that reads a `hooks/` path as text (`grep`, `cat`, `sed`, `readFileSync` ...).
- `units`: `[]` in wave 0.

## Differences from the 0100 §7(a) table (informational)

- The table's bucket sizes (B 62, A+B 101, A 5, C 12) were counted at an earlier tree. At this tree the heuristic gives
  contract 72, mixed 67, internal 17, static 28, with the new suites. A `lib-*.mjs` mention that is not an import form is not a
  lib import here, which moves suites from `mixed` to `contract`.
- `reads_source` counts 45 at this tree against the table's 36.
- `covers` is the direct reference set. A suite that spawns `msg.mjs` is not selected by a change to a lib that `msg.mjs`
  imports. (0101 §9 specifies the direct set.)
